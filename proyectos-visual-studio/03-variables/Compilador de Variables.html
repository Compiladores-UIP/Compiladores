BProblema que resuelve

Antes de usar un dato, hay que declararlo.

Todo programa guarda datos en variables. Para hacerlo, el lenguaje necesita saber qué tipo de dato es, cómo se llama y qué valor inicial tiene. En C# eso se escribe int edad = 25;, una sintaxis que al principio cuesta leer.

Este mini-compilador acepta las mismas declaraciones escritas en español. Revisa que estén bien formadas y que el valor corresponda al tipo. Si todo está correcto, genera un programa de C# que compila y se ejecuta en .NET. Si hay un error, indica la fase, la línea y cómo corregirlo.

DTokens identificados
Las unidades léxicas del lenguaje.

        
El analizador léxico recorre el código carácter por carácter y agrupa cada palabra, número o símbolo en un token. Lo que no reconoce se marca como TOKEN_DESCONOCIDO y se reporta como error léxico.

EAnálisis sintáctico
La gramática y el árbol que construye.

        
El analizador sintáctico revisa que los tokens de cada línea sigan esta gramática y arma el árbol. Después, el análisis semántico valida que la variable no exista, que las variables usadas estén declaradas y que el valor sea del tipo correcto.

      


<programa>    ::= { <sentencia> }
<sentencia>   ::= <declaracion> | <impresion>
<declaracion> ::= <tipo> IDENTIFICADOR "=" <valor> [ ";" ]
<impresion>   ::= ( IMPRIMIR | MOSTRAR ) <valor> [ ";" ]
<tipo>        ::= ENTERO | DECIMAL | TEXTO | BOOLEANO
<valor>       ::= NUMERO | DECIMAL | CADENA
                | VERDADERO | FALSO | IDENTIFICADOR

        
Programa
├─ Declaración (línea 1)
│  ├─ Tipo: ENTERO
│  ├─ Identificador: edad
│  ├─ Operador: =
│  └─ Valor: 25
└─ Impresión (línea 2)
   └─ Valor: edad

      

      

        

          
Validación semánticaEjemplo que la rompe

          
            
El valor debe ser compatible con el tipo (DECIMAL acepta ENTERO, al revés no)ENTERO edad = 20.5

            
Una variable se usa solo si ya fue declaradaIMPRIMIR apellido

            
Una variable se declara una sola vezENTERO edad = 21

            
El nombre no puede ser una palabra reservada de C#ENTERO int = 4

          
        

      

    

  


  
  

    

      
FCódigo generado
Cada línea tiene su equivalente en C#.

      

        

          

            
Lenguaje fuenteC#

            
          

        

        
using System;

class Programa
{
    static void Main()
    {
        int edad = 25;
        string nombre = "Carlos";
        double promedio = 91.5;
        bool activo = true;
        Console.WriteLine(nombre);
        Console.WriteLine(edad);
        Console.WriteLine(promedio);
        Console.WriteLine(activo);
    }
}

HPruebas
Un caso correcto y errores controlados.

        
Cada error indica la fase que lo detectó, la línea, la columna y una sugerencia. Usa “Probar” para cargarlo en el laboratorio.

      

        

          Caso correcto
          
ENTERO edad = 25
TEXTO nombre = "Carlos"
IMPRIMIR nombre
IMPRIMIR edad

          
Resultado esperado: se genera el C# y la consola muestra Carlos y 25.

          
        

        

          Caso incorrecto
          
ENTERO edad = 20.5

          
Mensaje esperado: Error semántico (línea 1, columna 15): No se puede guardar un valor DECIMAL en una variable ENTERO.
→ Un ENTERO no guarda decimales. Usa DECIMAL o quita la parte decimal.

          
        

      

      

        
Otros errores que detecta

        

          
TEXTO nombre = CarlosSemántico: La variable "Carlos" no ha sido declarada. → escríbelo entre comillas

          
entero nota = 90Sintáctico: "entero" no se reconoce como palabra clave. → ENTERO va en mayúsculas

          
ENTERO = 5Sintáctico: Se esperaba el nombre de la variable y se encontró "=".

          
DECIMAL 2promedio = 8.5Léxico: "2promedio" no es un identificador válido: no puede empezar con un número.

          
BOOLEANO activo = "si"Semántico: No se puede guardar un valor TEXTO en una variable BOOLEANO.

          
TEXTO saludo = "HolaLéxico: Texto sin cerrar: falta la comilla doble final.
